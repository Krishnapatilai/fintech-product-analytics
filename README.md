# Fintech Product Performance & Analytics

This project analyzes core product performance metrics for a fintech platform, focusing on funnel conversion, feature adoption, and user retention.

It demonstrates how business objectives can be translated into measurable KPIs and executive-ready dashboards to support product and leadership decision-making.

---

## 📊 Project Scope

### 1. Funnel & Retention Analysis
- Evaluated user progression: Signup → KYC → First Transaction → Repeat Usage
- Identified 40%+ activation drop-off during onboarding
- Calculated activation and retention KPIs

### 2. Feature Adoption Analysis
- Measured feature usage rates across user segments
- Identified high-impact and underutilized features
- Supported roadmap prioritization through usage insights

---

## 🛠 Tools Used

- SQL (SQLite / PostgreSQL)
- Excel (Dashboard & KPI Visualization)
- CSV Data Processing

---

## 📈 Key Insights

- Strong KYC completion but significant activation friction
- Retention improves significantly after first successful transaction
- Feature adoption insights indicate prioritization opportunities
