# Fintech Product Performance & Analytics

This project analyzes core product performance metrics for a fintech platform.

## Objectives
- Measure funnel conversion
- Track feature adoption
- Analyze retention patterns
- Provide data-driven product recommendations

## Tech Stack
- SQL (SQLite / PostgreSQL)
- Excel / Google Sheets
- Product KPI Framework

## Project Structure
- /sql → Analysis queries
- /dashboard → KPI dashboards
- /insights → Executive summary
- /data → Sample datasets

## Key Metrics
- Adoption Rate
- Funnel Conversion %
- Retention
- Segment-wise Usage

Designed to simulate real-world Product Analyst decision support workflows.
